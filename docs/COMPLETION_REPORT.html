Reka bentuk litar (ringkasan net)

RP2350B (U1) — MCU keselamatan/aktuator: QSPI→flash U3, SPI→ADC U6 & DAC U7, UART↔ESP32-S3, kawalan pam/kipas (PUMP_CTRL/FAN_CTRL), watchdog feed, SWD debug.
ESP32-S3 (U2) — MCU UI/Wi-Fi: factory_config GPIO (NTC=1, pam/kipas PWM/SSR=3-5, ECU=6, I2C=8/9, SD=10-13, RGB=38), UART↔RP2350B, QSPI→flash U4 + PSRAM U5 (terkongsi SPI0).
Kuasa — VBAT(12V)→buck U8→+5V→LDO U9→+3.3V→penapis→+3.3VA; DVDD=LDO dalaman RP2350.
Penderia — ADC 24-bit U6 (NTC, arus pam/kipas, voltan), BME280 U10, DS3231 U11, INA226 U12.
Aktuator — BTS50015 U14 (pam) & U15 (kipas), Q1 MOSFET, watchdog TPL5010 U13.

Skrip Sync GitHub (satu-klik)

Linux / Mac / Git Bash: tools/sync_github.sh
Windows CMD: tools\sync_github.bat

Perintah:
  ./sync_github.sh — tarik dari GitHub ke PC (lalai)
  ./sync_github.sh push — dorong dari PC ke GitHub
  ./sync_github.sh status — tunjuk perbezaan
  ./sync_github.sh clone — muat turun baharu

Sebelum guna: edit fail, tampal GITHUB_TOKEN anda (dari github.com/settings/tokens), tetapkan LOCAL_DIR.
Reproducibility: python3.12 tools/fix_schematic.py & python3.12 tools/fix_pcb.py · Pengesahan: python3.11 tools/verify_release.py & tools/verify_control_math.py
Sync: tools/sync_github.sh (Linux/Mac) atau tools/sync_github.bat (Windows)
Setiap pemetakan pin→net boleh ditelusuri ke factory_config.h atau pelan halaman P01–P15.
