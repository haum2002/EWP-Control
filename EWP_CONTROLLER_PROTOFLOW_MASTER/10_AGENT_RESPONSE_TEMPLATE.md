# REQUIRED AGENT RESPONSE

After every work unit, report:

## 1. WORK PERFORMED
Actual changes.

## 2. PAGES MODIFIED
Exact pages.

## 3. COMPONENTS
RefDes + exact MPN + package.

## 4. SOURCES
Datasheet/reference/design source.

## 5. ELECTRICAL CHECK
Power pins, floating pins, nets, polarity and required connections.

## 6. ERC/DRC
Actual result, not an assumption.

## 7. REQUIREMENT CHECK
Passed requirements.

## 8. FAILURES
Every unresolved required problem.

## 9. DATA_INSUFFICIENT
Only genuine unknowns.

## 10. NEXT ACTION
Only after prerequisites pass.

Allowed: "Gate 1 PASSED — verified."
Not allowed: "Complete" while required errors remain.

If a required error exists: "NOT COMPLETE — correction required." Then fix it and recheck.
